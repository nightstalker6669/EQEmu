## Scope and counting

- Inventory compiled from retained owner evidence; no new AA feature implementation, database or historical audit, build, runtime change or gameplay testing is claimed.
- No all-AAs-complete claim or defensible historical denominator. New-row next=-1 is a finite reconstruction boundary, not an original terminal rank.
- Native class masks are retained. Class membership does not bypass race, heritage, deity, level, prerequisite, grant-only, book, client-version or earned-acquisition restrictions.
- Raw expansion IDs and captured baseline costs/levels are preserved. Zero means unspecified retained value here; Drakkin expansion3 is an inherited reconstruction field, not TSS-era authentication.
- Published source, applied data, historical cache/install receipts, serving deployment and native gameplay acceptance are distinct. No current serving-state refresh was performed.
- Origin and knight packages are published integration source; merged release1958584a was reported built/published and not deployed in the last coordinator baseline. Catalogue commit da7b6090 confirms publication, not current runtime activation.
- 75 distinct named ability families / 198 distinct changed rank IDs = 125 added/restored plus 73 existing ranks affected. The 1,804 class-membership rows repeat shared ranks; they are not global additions.
- Change-kind totals overlap. A restored rank can also have an eligibility correction. Same-name families with different stable IDs remain separate.
- Class pages sort by retained native rank level, then name and rank. Acquisition minimum is a separate book/access requirement; unknown values remain unknown.
- No rank in this packet is marked native-gameplay-proven. Source publication, applied data and historical install/cache evidence do not establish current activation or native acceptance.
- Drakkin breath eligibility requires base race 522, race mask 32768 and the exact heritage 0–5 / mask 1,2,4,8,16,32. All-class eligibility does not grant these breaths to other races.
- Hero’s Barracks is an unchanged-definition finite-H interface reference; Pack Hunt rank 8 is held; incidental unresolved handler consumer 30150 and disabled audit drafts are excluded from named completed totals.
