# Owned click-only Objects

`eq.create_transient_click_object(owner, model, x, y, z, heading)` returns `{ entity_id, token }`, or no handle if creation fails. `eq.remove_transient_click_object(owner, entity_id, token)` removes only the matching live owned instance. Stale, foreign, DB-backed, item-bearing, ground-spawn, and player-drop targets are rejected. Keep the numeric ID and UUID token for later cleanup; event Object wrappers are views for the current callback, not permanent handles.

The helper uses a real native Object with no item/world-container instance or DB identity. It fixes the mode to click-only, preserves authored coordinates, and blocks persistence, item injection, type changes, and reassignment of its allocated entity ID. It opens no tradeskill window, creates no cursor item or loot credit, and uses no proxy item or door. Existing Object paths retain their behavior. The new click branch reuses the existing zero-drop-ID click cancellation acknowledgement shape; native visual/ack acceptance remains untested.

Player and zone click-object events receive numeric `e.object_id` from the captured ingress ID. Current callback order is preserved. An Object-specific RAII pin spans default click behavior and both events, so removal cannot destroy the Object or recycle its ID while callback code still uses it. The three Object retirement sites defer only pinned deletions; unpinned objects still delete immediately. Devtools requires the original ID/pointer to remain registered. Native pickup callbacks and existing inventory/tradeskill behavior remain in place.

The isolated candidate targets the combined AA-002 plus staged ground-capacity source, retaining those changes. Only seven source paths change. There is no wire layout, database schema, client executable, quest content, or generic entity ownership framework change. A single offline ASan/UBSan harness using actual candidate lifetime/retirement/cleanup methods passed self-removal, nested retirement, ID reuse, and stale/foreign lease checks. This is not a full server build, deployed fix, reproduced prior crash, or native client acceptance.
