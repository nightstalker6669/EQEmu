# RRC060 Eron pottery, tailoring, and Shadowspike recipes

Adds six missing recipes: Soot Bound Ceramic Clay, Unfired Eron's Ceramic Setting, Eron's Ceramic Setting, Eron's Threaded Web, Shadowspike Arrow Tip, and Shadowspike Arrow. Every primary formula explicitly requires scribing. The pottery recipes use Eron's Ceramic Setting Notes (36459), the web uses Eron's Thread (36471), and both Shadowspike recipes use Making Shadowspike Arrows (36588). Native book filenames, text hashes, languages, and unique native name lookups are guarded before and after insertion. Books, items, and player records are unchanged.

Source quantities, yield one, and numeric trivials are preserved. Soot clay consumes seven soot and one water. The web pattern and arrow-tip mold return on success and failure. Container links retain the native kiln, wheel, sewing-kit, forge, and fletching-kit classes and capacities. The six formulas specify no skill minimum. Source name Shadowspike Arrow (Expendable) resolves explicitly to native item 36592, Shadowspike Arrow; that native identity is preserved.

Energized thread is excluded because its authored book requires a strong static field and enforcement is unresolved. The web recipe only consumes already energized thread. Nine Shadow Box formulas remain held for the authored altar, time, and opening-order conditions. Two other smithing formulas are deferred while their learning requirements are resolved. Refined Steamwork Oil has no direct manufacturing recipe on its primary page.

IDs 3093575–3093580 contain six recipes and 29 entries. Application uses a guarded additive transaction, affected-row backup/readback, and a rollback limited to this batch. Maintained primary formulas and native authored books support the data; neither an immutable May 2013 export nor native client combine acceptance is claimed.
