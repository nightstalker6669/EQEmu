# RRC069 Crescent Reach Research alternative kits

Adds sixteen explicit container links to existing recipes12745–12748: Simple Quill, Simple Book Binding, Simple Ink, and Simple Blank Book. Each current primary formula and the TSS Research training guide lists Tome Binding Kit41555, Prayer Writing Kit41631, Hybrid Research Kit41632, Song Writing Kit41633 and the already-linked Spell Research Kit93492.

All five native kits have bagtype11, ten slots and bagsize3. Each source formula uses no more than three component units, all native ingredients fit, and the existing class restrictions are retained. Four exact recipe definitions and nineteen full old entries are guarded and preserved, including learning0, skill minimums, tool success/failure returns and the original kit links. This patch adds no recipe, NPC/task, item or player changes. Rollback requires the exact35-entry postimage and deletes only the sixteen added links.

The quest guide was created2007 and currently modified2021. These mutable views support qualified TSS context, not an immutable May2013 record for every kit. Native execution/task acceptance is untested. Other Research quest outputs with no producer and uncertain-trivial formulas are separate reviews.
