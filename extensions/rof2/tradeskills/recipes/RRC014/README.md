# RRC014: Restore source-named cultural forge access

This data-only proposal adds 58 container entries to 58 existing Smithing recipes: type36 for46 Northman Forge formulas and type33 for12 Ogre Forge formulas. It adds no recipes, reserves no recipe IDs, and preserves all16fields of every target recipe plus all465existing entry IDs and fields. Every existing type47entry remains intact. The exact target preimages,58logical additions and523-entry logical postimages are included in batch.json; rollback deletes only those exact58additions.

Every target has an independently checked exact current formula: output, component quantities, success/failure returns and trivial match123explicit source-to-native item references. This is not output-name-only matching. Fresh read-only target readback confirms all58/465preimages, and structural review against all enabled Smithing recipes finds no same-input-multiset collision at the proposed36/33container types. Current static world objects are Halas row40/type36 and Oggok row19/type33; both exact station identities are guarded. The current raw world data and legacy/item enums agree on these types. Conflicting modern enum labels are not used as client truth, and no enum/core edit is included.

The captured [Barbarian old-cultural catalogue](https://www.eqtraders.com/recipes/recipe_page.php?article=300&rc=BAR&rsa=Smithing&sub=cultural) names Northman Forge; the [Ogre catalogue](https://www.eqtraders.com/recipes/recipe_page.php?article=315&rc=OGR&rsa=Smithing&sub=cultural) names Ogre Forge. All58current target records instead have only type47, which current world data places in Grobb. The reviewed source does not establish47as an intentional historical alternate. This supports adding the missing source-named stations; it does not authorize deleting existing/custom47scope. No such removal is proposed.

Each target is bound to one of five pre-cutoff families:24Northman Ring,6Northman weapon,12Helanic Tundra,4Black Lace-boned and12Blackened Darkscale. [March2005Halas forge reports](https://mboards.eqtraders.com/eq/forum/tradeskills/smithing/21261-where-is-the-northman-forge) describe successful Northman Ring and Helanic combines, including complete bracer/cloak ingredient maps and a cultural-forge display-name problem. [April2003Blue Diamond discussion](https://mboards.eqtraders.com/eq/forum/tradeskills/general-trade-skill-discussion/6609-blue-diamond-armors-current-state-and-shortcomings) identifies Helanic, Black Lace-boned and Blackened Darkscale families. A [May2003Ogre artisan post](https://mboards.eqtraders.com/eq/forum/marketplace/marketplace-forums/tunare/7219-blackened-crimson-fulvous-darkscale-splint-ogr-trl-armor) offers complete Darkscale sets and cites the Ogre crafting recipes. These are current renderings of period player reports, not immutable snapshots or per-formula May2013numeric certification. No existing formula value is changed.

The source’s Barbarian/Ogre crafting restrictions are distinct from item wear-race. No equivalent cultural actor-race check was located in the two reviewed server combine paths; client enforcement remains unaccepted. This proposal restores source-named station availability only and does not claim complete cultural race enforcement, a native combine, or an engine fix. No quest, loot, reward, learning, character-state or runtime change is included. This limitation remains explicit for coordinator review.

Apply requires a fresh strict MariaDB10.11session, full exact target preimages,123item identities, two station identities and no new-container input collision. It accepts wholly absent or wholly exact58additions, refuses partial/wrong-role/foreign entries, checks full preserved target fields before and after writes, verifies exact deltas and commits explicitly. Exact reapply is idempotent. Rollback requires the whole exact added set and unchanged target base; all learned/made references remain because no recipe is deleted. Crafted items and AUTO_INCREMENT highwater are not rewound. STRUCTURAL-CHECKS.json is offline source evidence; this proposal has not been SQL-rehearsed, published or applied.
