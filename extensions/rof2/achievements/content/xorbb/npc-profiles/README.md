# Required NPC profile components

These are required source components, all unapplied. Use the combined migration candidate, not individual files.

`joint/` is the NPC owner's exact guarded component for 136 stat updates and 24 caster-AI bindings, including eighteen new Wizard AI rows. It replaces the separate stat and AI apply scripts. The initial owned-column union is locked and verified before its writes; the intended stat and spell-list postimages are merged. Twenty-six held dialogue, prisoner, smoke and spill actors are preserved. The normal-family reference JSON retains the default templates and intake, not another apply path.

`prior-world/` retains the existing 9344 component and its 21-profile ownership. The combined wrapper includes the full earlier component once if absent. If earlier tasks are present, it checks all derived owned postimages and namespace counts before omitting duplicate writes. Partial or different content refuses. A database version number is not installation proof.

`scenes/` contains the five reserved ephemeral definitions. The outer wrapper guards their identities and direct spawn/pet references. Scripts own target, stage, run and cleanup behavior; no permanent scene spawn rows are added.

All balance templates and selected generic class spellbooks are labelled configurable reconstructions. The Wizard fallback isolates seventeen existing entries and omits two problematic combat sword summons; it changes no shared spell list or pet definition. These are not recovered original RoF spellbooks or native combat acceptance. The portable scene JSON removes only a private source path and retains its original source hash.

Routine DDL precedes the one outer transaction. No component may independently commit, reload the server or activate quests. The installed binary and native encounter acceptance remain separate evidence.
