Nothing is registered with an installer. No database, installed script, source build or client action is included.

No new NPC, spawn, loot-table or spell-list IDs are allocated. All unknown combat values and loot rates stay null; no previously authorized NPC-stat reconstruction default has been used. Cragbeak's period4.3million HP report is retained as an approximate observation, not a chosen database value.

Target eligibility and caster binding must be resolved before script generation. Existing cure/fade triggers must not be duplicated by quest damage callbacks.

The general guide supports one Dreadmote when a named drop is selected. Exact rate, per-NPC pool/weights, Glowing inclusion and other loot remain unknown. Current aggregate lists are association evidence, not a complete period loot contract. No guaranteed drop or uniform lottery is proposed.

Before activation, resolve: (1) accepted original combat stats or an explicitly approved, clearly labelled reconstruction policy; (2) Iremaw target/caster/movement semantics and first-cast timing; (3) original per-provider pool, rate and complete loot contract; (4) scoped implementation and fresh ID/consumer checks for any later allocation. These are concrete completion inputs for this owned proposal, not a request to find another owner. Shared deployment still requires coordinator review.
